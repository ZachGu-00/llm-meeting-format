# Current paper results

These files are generated by `scripts/reproduce.py` from the frozen measurements. Table numbering and displayed values match the current manuscript.

| File | Paper content |
|---|---|
| `format_effects.csv` | Resize and regroup RMS by model and weighting |
| `scope_checks.csv` | Main, further-topic, further-model, and readout checks |
| `predictor_scores.csv` | All five predictors for resize and regroup |
| `predictor_gains.csv` | Weight-form and aggregation-placement comparisons |
| `majority_shifts.csv` | Observed and predicted majority-directed shifts |
| `size_weights.csv` | Transferred Size weights and total-influence ratios |
| `auxiliary_averaging.csv` | Equal-effective-weight counterexample |
| `logit_dispersion.csv` | Dispersion and Jensen-gap relationship |
| `micro_summary.csv` | Count, neutral-statement, and fixed-share results |
| `model_revisions.csv` | Model identities, roles, and pinned revisions |
| `tables/` | The nine manuscript tables as LaTeX rows |
| `verification.json` | Reproduction counts, errors, and manuscript checks |

Topic-level and composition-level files provide the inputs for the paper's comparisons. Confidence intervals are pointwise and do not establish an effect in every model. No new model responses were generated for this release.
